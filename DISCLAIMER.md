# Disclaimer

WAZ Control is a personal Unraid WebUI/dashboard customization project developed and tested against one specific server.

**It is not designed to work correctly on every stock Unraid installation. It is not a supported Community Applications plugin.**

The project relies on third-party plugins, Unraid runtime files, Linux system interfaces, hardware-specific sensors, Docker behavior, and WebUI DOM structures that may change without notice. Installing or adapting it may produce incorrect telemetry, conflict with another WebUI modification, stop working after an upgrade, or make part of the WebUI unusable.

Before installing:

1. Read [docs/DEPENDENCIES.md](docs/DEPENDENCIES.md).
2. Read [docs/RECOVERY.md](docs/RECOVERY.md).
3. Confirm that terminal or SSH access works.
4. Back up the server flash configuration.
5. Understand the exact paths owned by this plugin.
